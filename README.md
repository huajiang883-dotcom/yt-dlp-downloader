# yt-dlp 视频下载器

一个面向普通用户的 yt-dlp 图形界面：打开程序 → 粘贴视频链接 → 选择保存文件夹 → 一键下载。无需安装，无需配置，解压即用。

## 功能特性

- 粘贴链接一键下载（支持多行粘贴，一次下载多个）
- 始终下载最高画质（最佳视频 + 最佳音频自动合并）
- 窗口置顶（钉在屏幕上）、自由拉伸放大
- 全局快捷键 Ctrl+Shift+Y：在任何程序里复制链接后按下，自动开始下载
- 一键检查更新 yt-dlp / ffmpeg（可勾选开机自动检查；解压内置在程序中，零依赖）
- 便携设计：整个文件夹拷贝即用，配置自动保存
- 找不到 ffmpeg 时自动引导下载安装，绝不降级画质

## 使用

1. 在本仓库右侧的 Releases 中下载 `yt-dlp视频下载器_便携版.zip`
2. 解压到任意文件夹（例如 D:\便携版）
3. 双击 `yt-dlp视频下载器.exe`
4. 粘贴视频链接 → 选择保存文件夹 → 点「开始下载」

详细说明见 zip 内的《使用说明.txt》。

> 提示：首次运行若弹出「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可（程序未做数字签名，属正常提示）。
