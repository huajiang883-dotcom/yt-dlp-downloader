# 编译说明

程序用 C 语言 + Win32 API 编写，无任何第三方依赖，编译需要 MinGW-w64 工具链。

## 编译（推荐：Linux 交叉编译，任何 MinGW-w64 均可）

    x86_64-w64-mingw32-windres -O coff app.rc -o app_res.o
    x86_64-w64-mingw32-gcc -O2 -municode -mwindows main.c ziputil.c app_res.o \
        -o yt-dlp视频下载器.exe \
        -luser32 -lgdi32 -lshell32 -lole32 -luuid -lcomctl32 -lwininet

也可以用 llvm-mingw：

    x86_64-w64-mingw32-windres app.rc -O coff -o app.res
    x86_64-w64-mingw32-clang -O2 -municode -mwindows main.c ziputil.c app.res \
        -o yt-dlp视频下载器.exe -luser32 -lgdi32 -lshell32 -lole32 -luuid \
        -lcomctl32 -lwininet

（图标可通过 python3 gen_icon.py 重新生成；.res 也可用 gen_res.py 生成，
但 lld 链接器对 .res 支持不全，优先用 windres。）

## 文件说明

- main.c         全部程序逻辑（约 1500 行，带中文注释）
- ziputil.c/h    内置 ZIP 读取 + 手写 RFC1951 inflate（无第三方依赖，
                 替代 PowerShell Expand-Archive 解压 ffmpeg 包）
- app.rc         资源脚本（图标 + 清单）
- app.manifest   程序清单：asInvoker、系统 DPI 感知、comctl32 v6 视觉样式
- app.ico        程序图标
- gen_icon.py    图标生成脚本（纯 Python 标准库，无依赖）

## 主要设计（v2.1）

- 下载参数：--newline --windows-filenames --encoding utf-8 [--no-playlist] -- URL...
- 强制最高画质：无 ffmpeg 时弹窗引导自动下载安装（MB_YESNO + 后台安装线程），
  安装成功自动继续下载；绝不使用 -f b 降级
- yt-dlp 查找顺序：配置 → 程序同目录（便携优先）→ PATH → D:\ → Python Scripts
- ffmpeg 查找顺序：程序同目录 → PATH → yt-dlp 同目录 → D:\
- 全局快捷键 Ctrl+Shift+Y（RegisterHotKey + WM_HOTKEY + 剪贴板读取；
  支持 http(s):// 与 www. 开头）
- 窗口置顶：SetWindowPos(HWND_TOPMOST/NOTOPMOST)，状态存 config
- 更新：yt-dlp 版本查询 GitHub API → 失败自动兜底 PyPI JSON（国内网络友好），
  版本比较为数字分段比较（忽略前导零）；exe 本体仍从 GitHub 资产下载。
  ffmpeg 走 gyan.dev 的 Last-Modified 比较 + zip 下载 + 内置 inflate 解压；
  ffmpeg 已存在但无版本记录时记录版本并跳过下载（便携包友好）。
  均下载到程序同目录（便携模式）；空文件一律视为无效。
- 更新源可通过 config.ini 覆盖：YtDlpApiUrl / FfmpegZipUrl（测试用）
- 网络：WinINet（InternetOpenUrl/HttpQueryInfo），带连接/接收超时，
  下载校验 Content-Length
- 日志读取线程 UTF-8 逐行解码（失败回退 ANSI），PostMessage 投递到主线程
- 窗口可拉伸：WM_SIZE 全量重排（LayoutControls），最小 520x430
- 配置：%APPDATA%\YTDownloader\config.ini
  （OutDir/YtDlp/Playlist/Topmost/AutoUpdate/FfmpegVer/YtDlpApiUrl/FfmpegZipUrl）
- DPI：系统 DPI 感知（manifest + SetProcessDpiAwarenessContext 兜底），布局按 dpi/96 缩放
